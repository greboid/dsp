= Docker Socket Proxy

It is intended to be as simple as possible to allow a proxy to serve container without needing full access to the
docker socket by exposing the docker socket (unix socket) via HTTP

== Allowed endpoints
- `GET /`: All GET requests are allowed
- `POST /containers/+{id}+/kill`: Allowed only with permitted signals
- `POST /images/create`: Allowed only if `-allowPulls` is enabled
- `POST /{containers,images,networks,volumes,build}/prune`: Allowed only if `-allowPrune` is enabled
- `POST /containers/+{id}+/attach`, `POST /containers/+{id}+/exec`, `POST /exec/+{id}+/start`, `POST /exec/+{id}+/resize`: Allowed only if `-allowExec` is enabled
- `POST /containers/create`, `POST /containers/+{id}+/start`, `POST /containers/+{id}+/wait`, `DELETE /containers/+{id}+`:
  Allowed only if `-allowCreate` is enabled
- All other requests (`POST`, `PUT`, `DELETE`, ...) are denied

Streaming endpoints (events, stats, logs, attach, archive, pulls, exec and the endpoints above) are not subject to the
30 second server timeout.

WARNING: `-allowExec` permits running any command in any container and writing to container stdin via attach. `-allowCreate` permits creating containers with any
mounts or privileges, which is equivalent to root on the host. `-allowAll` passes every request to the socket and
disables all other checks.

== Configuration Options

The application accepts the following command-line flags, which can also be set via environment variables:

- `-socket` (default: `/var/run/docker.sock`): Path to the Docker socket
- `-proxyPort` (default: `8080`): Port for the proxy to listen on
- `-killSignals` (default: `HUP`): Space-separated list of permissible kill signals, if blank none are allowed
- `-allowPulls` (default: `false`): Allow pulling images
- `-allowPrune` (default: `false`): Allow pruning containers, images, networks, volumes and build cache
- `-allowExec` (default: `false`): Allow running commands in and attaching to containers
- `-allowCreate` (default: `false`): Allow creating, starting, waiting on and deleting containers
- `-allowAll` (default: `false`): Allow all requests

Environment variables: `SOCKET`, `PROXYPORT`, `KILLSIGNALS`, `ALLOWPULLS`, `ALLOWPRUNE`, `ALLOWEXEC`, `ALLOWCREATE`,
`ALLOWALL`

== Logging Options

- `-log.format` (default: `text`): Log format, either `text` or `json`
- `-log.level` (default: `info`): Minimum log level to output (`debug`, `info`, `warn`, `error`)

Environment variables: `LOG_FORMAT`, `LOG_LEVEL`
